## 三、接下来按顺序做什么(命令级)

```bash
cd /data/zilu/QseekLLM/src/post_train   # 所有命令在此目录,python 用 .venv/bin/python
```

**1. 等 v2 重建完成 → 对账抽检**
```bash
cat /data/zilu/data_unified_v2/manifest.json          # 各源 kept/dup/leak,与 docs/rebuild_v2_log.md §三 的预期核对
# 随机抽 30 条人检(复用审计时的方法):重点看 orca 的 boxed 是否与推理一致、ape210k 中文 CoT、无 boxed{proof}
```
预期关键数字:calc-ape210k sft≈148k / chinese-r1-math≈26k / metamathqa leak≈17(不再是 7.5万) / orca kept≈157k。

**2. 重建 heldout(修复 svamp 泄漏,必须在起训前)**
```bash
.venv/bin/python -m eval.build_heldout --out eval/heldout.jsonl
# 自动:对 v2 训练池 qhash 过滤 + competition-math 从 math-500 采样。看输出里"训练池过滤: 剔除 N 条"
```

**3. 启动 F2 训练(A800, card1)**
```bash
tmux new -s sft   # 或复用已有 sft 会话
bash SFT/run_foundation_v2_sft.sh
# 保存到 /data/zilu/fastrl/checkpoints/sft_foundation_v2,实验名 sft_foundation_v2,2 epoch,超参与 F1 相同
```

**4. 启动异步评测(A4000 card2,3,不阻塞训练)**
```bash
tmux new -s eval
.venv/bin/python -u -m eval.async_eval --ckpt-dir /data/zilu/fastrl/checkpoints/sft_foundation_v2 --gpu-candidates 2,3 --watch
# 产出 <ckpt>/eval_dumps/{metrics.jsonl, step_N/heldout.md};每 500 step 自动评新 checkpoint
```

**5. 跟踪与判读**
- 总 acc 与 per-source 曲线记到 `docs/eval_tracking.md`(已有 F1 的 11 个点作历史参照——**注意 F1 用的是 v1 测试集+脏数据,与 F2 不可直接比绝对值**,svamp 列尤其,F1 时泄漏虚高)。
- 重点观察(对照 F1 的短板):乘法类子源、cmath/中文输出质量(中文池新加 18 万,应有显著改善)、GSM-Plus 是否还贴地。

**6. F2 之后**(不急,见 training_plan v2):S3 难度课程(门禁=F2 收敛+P1 清零,P1 还剩 per-source 细粒度课程 eval 未建)→ S4 GRPO。
